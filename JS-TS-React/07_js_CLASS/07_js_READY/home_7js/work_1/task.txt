==============📣 При натисканні на кнопку форми Add
1. Отримати текст який користувач ввів в поле 
   з name="newtext"
2. Використовуючи DOM API JS створити елемент li з класом list-group-item, 
   та отриманим текстом
3. Додати створений li  до  елмента <ul id="lists">
Особливості 
- якщо список lists порожній, то просто додати li до списку
- якщо у списку є елементи li, то запитати у користувача під яким
  за рахунком номером додати елемент.
  При цьому:
  -- якщо користувач ввів число 0, або якщо введене число
     перевищує кількість елементів у списку, то елемент додати
     в кінець списку
   -- якщо користувач ввів коректне число, то додати елемент
      на відповідне місце


==============📣 При натисканні на кнопку Delete
1. видаляти елементи зі списку з id="lists"
- якщо список з id="lists" порожній, то вивести сповіщення користувачеві про це
- якщо в списку 1 елемент, видалити його
- якщо у списку більше 1 елемента, то запитати у користувача який
  за рахунком елемент треба видалити. При цьому:
  При цьому:
  -- якщо користувач ввів число 0, або якщо введене число
     перевищує кількість елементів у списку, то видаляти останній
     елемент списку
  -- якщо користувач ввів коректне число елемента, що видаляється, то видалити
     цей елемент зі списку
