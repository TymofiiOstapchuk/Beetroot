4. Options -> для кожної моделі існують свої
    їх можна знайти у відповідній моделі
    Наприклад для mansonry (https://isotope.metafizzy.co/layout-modes/masonry.html)
    - columnWidth
    - gutter
    - horizontalOrder
    - fitWidth
    - fitWidth

4.1 Робота без media-queries
 - Треба виставити в стилях ширину одного фото width: 300px;
   і в option виставити columnWidth
  - якщо хочемо центрування - виставляємо fitWidth: true
Наприклад
masonry: {
    columnWidth: 300,
    fitWidth: true
}

4.2 якщо працюємо з media-queries (де визначається ширина фото у %)
 columnWidth, fitWidth при цьому прибираємо
