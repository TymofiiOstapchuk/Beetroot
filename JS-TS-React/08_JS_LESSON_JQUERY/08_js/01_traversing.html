• EL.children("li") => відбір всіх прямих child
    EL.find("li") => відбір всіх child
  • EL.children('li:first-of-type') відбір першого child
    EL.find("li").first() => відбір першого child

    EL.find('li:nth-child(2)') => відбір всіх second прямых child, включаючи nested child

    EL.children('li:nth-child(2)') => відбір прямого 2-го child
    EL.children('li').eq(1) => відбір прямого 2-го child
  • EL.children('li').eq(2).next() => відбір наступного елемента після прямого 3-го child
    EL.children('li').eq(2).prev() => відбір попереднього елемента післе прямого 3-го child
    EL.children('li').eq(2).siblings() => відбір всіх соседних елементів після прямого 3-го child
  • $('li').parent() => у всіх элементов li відібрати прямых parents
    $('li').parents() => у всіх элементов li відібрати всіх parents
  • EL.closest('.mycls') => шукає parent елемент за вказаним селектором
    починаючи з себе Пошук зупиняється, як тільки знайдено перший елемент

    EL.parents('.mycls') => шукає всіх parents по селектору починаючи з прямого parent Пошук здійснюється до елемента html
