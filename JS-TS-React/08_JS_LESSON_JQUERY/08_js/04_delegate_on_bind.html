Events delegate

  • EL.bind(event, [data], handler)
    Установит обработчик handler на событие event для каждого из отобранных элементов. Например

    $('h2').bind('click', handler) => аналогично $('h2').on('click',handler)
  • EL.HELPER(event, handler)
    Например
    $('h2').click( handler) => то же самое что и $('h2').on('click', handler)
  • Использование on
    $('.test-box').on('click', '.test-el', handler)
