11. Refs
На відміну від state
- зберігається як current
- при зміні refs не викликається re-render.
- Mutable - можна змінювати current value поза rendering процесом

Використовуючи refs реалізувати при натисканні на кнопку
долучення елементів input
При цьому фокус повинен завжди повинен бути на крайньому
доданому елементі
