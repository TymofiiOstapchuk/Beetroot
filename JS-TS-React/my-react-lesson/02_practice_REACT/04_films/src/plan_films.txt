======================= 👩‍🎓 ЗАВДАННЯ СЛУХАЧАМ:

Вивести в компоненті GenresList.tsx список фільмів відповідно до жанру, 
який вибирається в компоненті MovieDetails

Для цього 
1. створити компонент pages/movies/GenresList.tsx

2. в компоненті pages/movies/MoviesPage.tsx додати відповідний Route на створений 
  компоннет GenresList.tsx для відробки лінків жанрів компонента
  MovieDetails 

3. в компоненті GenresList.tsx 
  - отримати id жанра
  - отримати з серверу список фільмів по цьому id
  - вивести список фильмів з пагінацією використовуючи компонент Movie.tsx 
 
API взяти з документації 
https://developers.themoviedb.org/3/discover/movie-discover
